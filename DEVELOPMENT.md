# Технический паспорт проекта (Samartsev AI Landing)

Этот файл содержит описание критических изменений и настроек, внесенных для успешного деплоя и работы чат-виджета. **Прочти это перед началом работы.**

## 1. Стек и Сборка (Vercel)
*   **Next.js**: Изначально стояла нестабильная версия (16.2.1), которая ломала сборку на Vercel. Проект откачен на **стабильную версию** (latest).
*   **TypeScript**: В проекте включен строгий линтинг. Были исправлены ошибки `any` в компонентах `ChatWidget`, `SolutionsSection`, `CasesSection` и других. **Не используйте `any`**, иначе Vercel отклонит деплой.
*   **Конфигурация**: `next.config.mjs` используется вместо `.ts`, чтобы избежать синтаксических ошибок в среде Node.js при сборке.

## 2. Связь с n8n (Backend)
Для обхода CORS и безопасной связи используется проксирование (Rewrites) в `next.config.mjs`.
*   **Путь на сайте**: `/api/n8n/:path*`
*   **Назначение**: Перенаправляет запросы на `process.env.N8N_BACKEND_URL`.
*   **Важно**: Все запросы из фронтенда (компонент `ChatWidget`) должны идти на относительный путь `/api/n8n/...`, а не на прямой адрес туннеля.

## 3. Переменные окружения (Vercel)
Для работы проекта в Vercel должны быть прописаны:
*   `N8N_BACKEND_URL`: Ссылка на туннель Cloudflare (без слэша на конце!).
*   `NEXT_PUBLIC_N8N_CHAT_WEBHOOK`: Путь к вебхуку (например, `/api/n8n/webhook-test/chat-widget`).
*   `NEXT_PUBLIC_TINA_CLIENT_ID`: ID из Tina Cloud.
*   `TINA_TOKEN`: Токен из Tina Cloud.

## 4. Локальная инфраструктура (n8n + Docker)
n8n запущен в Docker-связке с:
*   **Warp (Proxy)**: Для доступа к API OpenAI/Anthropic из регионов с ограничениями.
*   **Cloudflare Tunnel**: Для проброса локального порта 5678 в интернет. Используется протокол `http2` для стабильности.
*   **Важно**: При перезапуске Docker адрес туннеля меняется. Его нужно обновлять в `N8N_BACKEND_URL` в Vercel и делать **Redeploy**.

## 5. TinaCMS
*   Схема настроена в `/tina/config.ts`.
*   Контент хранится в `/content/`.
*   Для локальной разработки используйте `npm run dev`, для админки — `/admin`.
